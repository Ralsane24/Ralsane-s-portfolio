# Ralsane's — Gaming Portfolio

A responsive blue-and-white portfolio made with HTML, CSS, and JavaScript. Open `index.html` in a browser, or use VS Code's Live Server extension if already installed. No installation or build is required.

## Personalize

- Change the Ralsane's name, introduction, about text, and project previews in `index.html`.
- Set `portfolio.email` and the project descriptions in `script.js`.
- The Projects tab contains Castle Crashers, A Frame of an Animator’s Dream, and Making Fanarts, with supplied artwork in `assets/`. Each card opens the complete image and project description.
- The About tab includes Ralsane’s portrait and Mapúa University / cum laude biography.
- The contact setup dialog stores an email in your browser only. Set the email in `script.js` before sharing the website.
- Colors, layout, and animations are in `style.css`.
- The pixel theme is in `indie.css`; the tabbed game window and landscape are in `tabs.css`.
- `tabs.js` handles pixel transitions, keyboard tab navigation, and browser back/forward history. Each main tab shows its own screen; smaller displays scroll within the selected screen.

Chewy headings and buttons use a bundled local font. Inter body text loads from Google Fonts. The interface uses system fallback fonts when offline. Animations respect the device's reduced-motion preference.

`polish.css` contains the Chewy typography, larger controls, and readability refinements. The SFX button toggles interface sounds independently of the soundtrack.
